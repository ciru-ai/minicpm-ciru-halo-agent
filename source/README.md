# Runtime source

This directory preserves the exact model adapters, shared plugins, native kernel sources, and vLLM Python engine source used by the packaged release. The runtime archive additionally contains compiled libraries, dependencies, draft weights, and integrity metadata. Use the release installer for inference; this source tree is not a standalone pip project.

Engine revision: ed7ae705a. Upstream file names and development paths are retained for source identity. Public usage and performance documentation live at the repository root.
